# Requirements and Compatibility

Compatibility information must be confirmed against each published build. Do not assume that a release supports every Android device.

## General requirements

- An Android device capable of running the official Civilization VI Android release.
- A legitimate installation/license for the game.
- Sufficient free internal storage for the game and its data files.
- A backup of existing game data and saves before applying modifications.

## Version compatibility

Use only localization files explicitly marked as compatible with your game build. An incompatible APK or data package may cause installation errors, crashes, missing text, or corrupted data.
